# ТЗ: Light/Dark темы для QR-меню Common Coffee (ЖЁСТКАЯ ФИКСАЦИЯ)

Дата: 2026-08-23
Статус: обязательно к исполнению как написано. Любые «улучшения» вне списка ЗАПРЕЩЕНЫ.

## РАЗРЕШЕНО ИЗМЕНИТЬ
Только и исключительно следующее:
1. Добавить кнопку переключения темы в шапку (рядом с EN/VI).
2. Добавить стрелки прокрутки (← →) и текстовую подсказку около горизонтального списка категорий.
3. Добавить CSS для тёмной темы и переменную градиента шапки.
4. Добавить JS: применение темы, сохранение в localStorage, обработчики стрелок.

## ЗАПРЕЩЕНО (не трогать)
- Горизонтальную раскладку категорий — НЕ переделывать, только добавить стрелки/подсказку.
- Свайп категорий — СОХРАНИТЬ без изменений.
- Язык (EN/VI), корзину, логику заказа, структуру меню, цены, изображения.
- Любой рефакторинг существующего кода, не относящийся к теме/стрелкам.
- Тяжёлые библиотеки (только чистый CSS + vanilla JS, как сейчас).

## КОНКРЕТНЫЕ ТРЕБОВАНИЯ

### Темы = две нормальные дизайнерские темы (не инверсия)
- **Light** (текущая кофейная): primary `#8B4513`, фон `#FFF8F0`, карточки `#FFFFFF`, текст `#333`.
- **Dark** (глубокая угольно-кофейная): фон `#15110D`, карточки `#211A13`, текст `#F2E9DF`,
  primary (акцент) — тёплый янтарь `#E0A458`, бордер `#352A20`.

### Градиенты шапки — ЗАДАННОЕ направление (строго сверху вниз, 180deg)
- Light: `linear-gradient(180deg, #C8A27C 0%, #8B5E3C 100%)`
- Dark:  `linear-gradient(180deg, #2B2018 0%, #1A120B 100%)`
- Тот же градиент применяется к экрану загрузки.

### Сохранение состояния при смене темы (КРИТИЧНО)
Смена темы — ТОЛЬКО визуальный оверлей через `data-theme` на `<html>`.
При смене темы НЕ вызывать `initializeMenu()`, `renderItems()`, `renderCartModal()` и т.п.
Должны сохраняться: выбранный язык, содержимое корзины (позиции/количество), текущая категория,
открытые модальные окна. Тема сохраняется в `localStorage['cc-theme']` и восстанавливается при загрузке.

### Стрелки категорий
- Слева и справа от списка категорий — понятные стрелки `‹` / `›`.
- По клику прокручивают список на ~200px (smooth).
- Подсказка под списком: `← Swipe or scroll →` (EN) / `← Vuốt hoặc cuộn →` (VI), с переводом через data-en/data-vi.
- Свайп пальцем остаётся рабочим.
