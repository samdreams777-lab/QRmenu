# Отчёт: QR-меню Common Coffee (финальная доработка)

Дата проверки: 2026-08-23
Метод проверки: **функциональный тест в реальном браузере (Playwright, Chromium, mobile viewport 390×844)**, не только проверка файлов.

## Изменённые/созданные файлы
- `data/menu.json` — исправлены пути ко всем 56 изображениям (были обрезаны → не грузились); помечены 2 позиции `needs_review` (ошибка VI-названий Ambarella/Pineapple Juice).
- `index.html` — добавлены модалки заказа/успеха, `data-en`/`data-vi` на статических элементах, подключён `orderSender.js`.
- `script.js` — переписана логика: исправлен баг `btn.dataset[lang]` (давал «undefined»), корзина с переводом на лету, карточка товара, полный flow заказа, интеграция с email-модулем.
- `styles.css` — добавлены стили: кнопка «+» на карточке, бейдж количества, панель корзины, элементы корзины с фото, кнопки Place Order/Send Order, модалка успеха.
- `orderSender.js` — **новый** модуль отправки заказа на email (режим demo, с конфигом для production).
- `functional_test.py`, `image_coverage_test.py` — тесты.

## Реальные проблемы, найденные до исправления
1. **Все изображения были битыми** — пути в `menu.json` обрезаны и не совпадали с реальными файлами в `menu_photos/`.
2. **Переключатель EN/VI ломал интерфейс** — `btn.textContent = btn.dataset[lang]` возвращал `undefined` → кнопки языка превращались в «undefined».
3. **Оформление заказа не работало** — в корзине не было кнопки Place Order, у модалок заказа/успеха не было обработчиков.
4. **Корзина не переводилась** при смене языка (имя хранилось на момент добавления).
5. **Язык в модалках заказа/успеха не переключался** (статические элементы брали `data-*` только при загрузке).

## Что исправлено
- Все пути к изображениям сопоставлены с реальными файлами (0 битых).
- Баг переключателя языка устранён.
- Реализована полная корзина: добавление (кнопка «+» на карточке и в деталях), +/−, удаление, очистка, сумма в VND, счётчик.
- Реализован flow: Корзина → Place Order → модалка заказа с номером → Send Order (demo email) → модалка успеха → кнопка Google Review (открывает Google Maps).
- Перевод EN/VI теперь применяется везде, включая модалки.
